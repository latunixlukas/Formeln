# NTG Formeltrainer

Persönlicher Trainer zum **Formelnumstellen** für die NTG-Prüfung (Industriemeister Elektrotechnik, IHK Dortmund, November 2026).

- **Leicht:** Formel nach einer Größe umstellen, richtige Form auswählen (mit Zahlenprobe)
- **Mittel:** umstellen und mit Zahlen ausrechnen, Lösungsweg mit eingesetzten Werten
- **Schwer:** Rechenketten nach dem Muster echter Prüfungsaufgaben (E1–E6, S1–S6)
- **Formelblatt:** alle 51 Formeln mit jeder Umstellung, nach Gruppen
- **Fortschritt:** richtig/falsch je Thema, Countdown bis zur Prüfung (im Browser gespeichert)

Starten: `index.html` im Browser öffnen – keine Installation nötig.
Online stellen: in GitHub unter *Settings → Pages* den Branch auswählen, dann ist die Seite unter `https://latunixlukas.github.io/formeln/` erreichbar.
